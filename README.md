# Bitrix24 Box Handbook

Справочник по разработке под 1С-Битрикс и Bitrix24 Box: архитектура ядра,
D7 ORM, инфоблоки, кеширование, REST API, CRM, бизнес-процессы, приложения
маркетплейса и эксплуатация коробочной версии.

Каждая глава построена по одной схеме: **как это устроено внутри → как
делать правильно → где ломается в проде → рабочий код**. Примеры кода
запускаемые, а не иллюстративные: их можно положить в `/local/` и проверить
на инсталляции.

## Структура репозитория

```
docs/       теория: как устроено и почему работает именно так
examples/   рабочий код к каждой главе, разложенный по каталогам module-X-Y/
```

Каталог `examples/module-X-Y/` соответствует главе `docs/module-X-Y.md`.
Внутри — либо готовый модуль для `/local/modules/`, либо набор файлов,
которые копируются в `/local/` инсталляции.

## Требования

- PHP 8.1+ (примеры рассчитаны на 8.1–8.3, без deprecated-конструкций)
- 1С-Битрикс: Управление сайтом или Bitrix24 в коробочной версии
- Composer — для глав про автозагрузку и внешние зависимости

Примеры не привязаны к конкретной сборке: там, где поведение зависит от
версии ядра или отличий Box/Cloud, это указано в тексте главы.

## Соглашения по коду

- Новый код — на D7 (`Bitrix\Main\*`, `Entity\DataManager`, `Loader`,
  `EventManager`). Legacy-API используется только там, где альтернативы нет,
  и это помечено.
- Точка входа: права → CSRF → валидация → работа. SQL — только через ORM
  или плейсхолдеры. Вывод — через `htmlspecialcharsbx`.
- Любая запись в сущность сбрасывает связанный кеш.
- Повторный запрос не создаёт дубль: уникальные ключи, `request_id`,
  проверка перед вставкой.
