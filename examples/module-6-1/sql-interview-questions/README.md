# Задача 2: Типовые SQL-задачи через D7 ORM

## Что показывает

Пять "классических" задач, которые дают на собеседовании. Каждая — на конкретный приём D7.

| № | Задача | Что проверяет |
|---|--------|---------------|
| 1 | Заказы за 30 дней, статус N, PRICE > 5000 | Префиксы `>=`, `>`, DateTime |
| 2 | Топ-10 товаров по продажам | `SqlExpression('SUM()')`, `group`, `order` по агрегату |
| 3 | Заказы где CITY = 'Москва' | `ReferenceField` для JOIN по свойству |
| 4 | Сумма продаж по месяцам | `DATE_FORMAT` в select + `group` по вычисляемому |
| 5 | Менеджеры с >10 выполненными заказами | `having`, `IN` через `=@` |

## Senior-инсайты

1. **`filter` через связь** — `'PROP_VALUE.ORDER_PROPS.CODE' => 'CITY'` работает, потому что D7 разворачивает связи до конца. Но требует `runtime` с `ReferenceField`.

2. **INNER vs LEFT JOIN в `runtime`** — INNER для "должна быть", LEFT для "не должна быть" (заказы с товаром X, но без Y — классика).

3. **`having` для агрегатов** — `COUNT(*) > 10` в `having`, не `where`. Префикс в `filter` не работает с агрегатами.

4. **`=@` для IN** — `filter => ['=@ID' => [1,2,3]]`. Без префикса `=` массив превратится в AND (сработает неправильно).

5. **`DateTime('-30 days')`** — DateTime объект в фильтре, не строка. `new DateTime('2024-01-01')` для конкретной даты.

## Префиксы фильтра D7 — шпаргалка

| Префикс | Значение | SQL |
|---------|----------|-----|
| `=` или без | `=> 'N'` | `= 'N'` |
| `>`, `>=`, `<`, `<=` | `'>PRICE' => 100` | `PRICE > 100` |
| `!` или `!=` | `'!STATUS' => 'F'` | `STATUS != 'F'` |
| `><` | `'><DATE' => [$a, $b]` | `DATE BETWEEN a AND b` |
| `=@` | `'=@ID' => [1,2,3]` | `ID IN (1,2,3)` |
| `!@` | `'!@ID' => [1,2]` | `ID NOT IN (1,2)` |
| `%` | `'%NAME' => 'тест'` | `NAME LIKE '%тест%'` |
| `null` | `'USER_ID' => false` | `USER_ID IS NULL` |

## Что спросят

- «Чем `getList` отличается от `query()->exec()`?» — `getList` возвращает `ORM\Query\Result` с `fetch()`, `query()` — сырой `DB\Result` без ORM-связей.
- «Как посчитать количество без `COUNT(*)`?» — `getList` с `select => ['CNT' => SqlExpression('COUNT(*)')]`, group по нужному полю.
- «Что такое `fetchAll` vs `while(fetch)`?» — `fetchAll` загружает всё в память (опасно на больших данных), `while($r->fetch())` — поток.
