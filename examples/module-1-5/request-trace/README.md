# Инструмент: трассировка фаз запроса

## Что копировать

```
local/php_interface/init.php      →  /local/php_interface/init.php   (или одна строка в существующий)
local/php_interface/trace.php     →  /local/php_interface/trace.php
local/trace-page.php              →  /trace-page.php
```

Если `/local/php_interface/init.php` уже есть — не перезаписывай, добавь строку:

```php
require_once __DIR__ . '/trace.php';
```

## Как проверить

1. Скопировать файлы, открыть `/trace-page.php` — обычная страница, ничего лишнего.
2. Открыть `/trace-page.php?bx_trace=Y` под администратором — внизу страницы
   появится таблица фаз: `BX_STATE`, время от старта, дельта, память.
3. Посмотреть исходник страницы: `<meta name="description">` заполнен, хотя
   `SetPageProperty()` вызван **после** `header.php`.
4. Открыть `/upload/bx_trace_last.log` — там метка `OnAfterEpilog`, которой нет
   в HTML. Это доказательство: событие сработало уже после отдачи ответа.
5. Открыть ту же страницу без `?bx_trace=Y` — таблицы нет, `init.php` не
   выполнил ничего лишнего.

## Что должно получиться (порядок фаз)

| Фаза | `BX_STATE` | Смысл |
|---|---|---|
| `init.php` | `PB` | пролог до подключения шаблона |
| `OnBeforeProlog` | `PB` | ранний хук пролога (может отсутствовать в старых сборках — тогда строки нет) |
| `OnProlog` | `PB`/`PA` | пролог, `$USER` уже есть |
| `OnEpilog` | `EB` | эпилог начался, буфер ещё открыт |
| `OnBeforeEndBufferContent` | `EB` | перед сборкой отложенных колбэков |
| `OnEndBufferContent` | `EB` | **здесь и только здесь правится HTML** |
| `OnAfterEpilog` | `EV` | ответ уже отдан — только файл лога |

`BX_STATE` для `OnProlog` зависит от версии: событие вызывается внутри
`CMain::PrologActions()`, до `prolog_after.php`, поэтому ожидаем `PB`.

## Почему проверка прав в обработчике, а не при регистрации

`init.php` может выполниться раньше, чем `$USER` восстановлен из сессии. Если
проверять `IsAdmin()` в момент регистрации обработчика, решение будет принято по
незалогиненному пользователю. Поэтому регистрируем всегда, а права проверяем
внутри `OnEndBufferContent` — там `$USER` уже настоящий.

## Ограничения инструмента

- Работает только на коробке: нужен файловый доступ и `init.php`.
- `file_put_contents` в `/upload/` требует прав на запись; если каталога нет —
  создай или поменяй путь.
- `OnBeforeProlog` в некоторых версиях отсутствует: обработчик просто не
  вызовется, ошибки не будет.
