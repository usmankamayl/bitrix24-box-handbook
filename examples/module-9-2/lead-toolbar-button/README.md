# Пример: Кнопка в тулбаре лида (TOOLBAR-плейсмент)

## Описание

Виджет типа "кнопка", который добавляет кнопку **"Отправить в сервис"** в тулбар карточки лида. При клике открывается боковая панель (slider) с формой отправки.

## Как работает

1. `install.php` регистрирует плейсмент `CRM_LEAD_DETAIL_TOOLBAR` с опцией `type: slider`
2. В карточке лида появляется кнопка в тулбаре
3. При клике открывается слайдер с `widget.php`
4. Виджет получает `ID` лида из `PLACEMENT_OPTIONS`, загружает данные и отправляет комментарий

## Что демонстрирует

- ✅ TOOLBAR-плейсмент (кнопка вместо вкладки)
- ✅ Опция `type: slider` — открытие в боковой панели
- ✅ Загрузка данных сущности через `BX24.callMethod`
- ✅ Запись данных обратно (`crm.timeline.comment.add`)
- ✅ Уведомления через `BX24.showNotification`

## Отличие TAB от TOOLBAR

| TAB | TOOLBAR |
|-----|---------|
| Всегда видна как вкладка | Кнопка, открывает popup/slider |
| Загружается при открытии карточки | Загружается только при клике |
| Хорошо для аналитики | Хорошо для действий |
