# Пример: Виджет-вкладка в карточке сделки

## Описание

Виджет, который отображается как дополнительная вкладка в карточке сделки и показывает:
- Основную информацию о сделке (название, сумма, стадия, вероятность)
- Список привязанных контактов
- Список товаров в сделке

## Как работает

1. Приложение регистрирует виджет через `placement.bind` с кодом `CRM_DEAL_DETAIL_TAB`
2. Когда пользователь открывает карточку сделки, Bitrix24 загружает `widget.php` в iframe
3. Передает параметры:
   - `PLACEMENT_OPTIONS` — `{"ID": 123}` (ID сделки)
   - `AUTH_ID` — токен для REST API
4. Виджет загружает данные через `BX24.js` и отображает в HTML

## Установка

### 1. Зарегистрируй виджет

Измени в `install.php` свой домен и запусти:

```bash
php install.php
```

### 2. Открой карточку сделки

Перейди в Bitrix24 → CRM → Сделки → открой любую сделку → вкладка "Информация о сделке"

## Что демонстрирует

- ✅ Регистрация виджета через `placement.bind`
- ✅ Использование плейсмента `CRM_DEAL_DETAIL_TAB`
- ✅ Получение `PLACEMENT_OPTIONS` с ID сделки
- ✅ Загрузка данных через `BX24.callMethod`
- ✅ Автоматическая подгонка размера (`BX24.fitWindow`)
- ✅ Работа с несколькими методами API
