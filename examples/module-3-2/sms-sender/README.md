# Отправка SMS (SMS Sender)

Компонент для отправки SMS через сервис SMSC.ru с поддержкой AJAX.

## Описание

Этот компонент демонстрирует:
- Отправку POST-запросов к внешнему API
- Работу с параметрами авторизации (логин/пароль)
- AJAX-отправку формы без перезагрузки страницы
- Валидацию данных на стороне сервера
- Форматирование номера телефона
- Обработку различных ошибок API
- Логирование запросов с защитой конфиденциальных данных

## Структура файлов

```
sms-sender/
```

## Установка

### 1. Зарегистрируйтесь на SMSC.ru

1. Перейдите на [smsc.ru](https://smsc.ru/)
2. Зарегистрируйте аккаунт
3. Пополните баланс (минимум 50 рублей)
4. Получите логин и пароль

### 2. Скопируйте компонент

```bash
cp -r sms-sender /path/to/bitrix/components/custom/sms.sender
```

### 3. Подключите на странице

```php
<?$APPLICATION->IncludeComponent(
    "custom:sms.sender",
    ".default",
    [
        "API_LOGIN" => "ваш_логин",
        "API_PASSWORD" => "ваш_пароль",
        "SENDER_NAME" => "MyCompany",  // Опционально
        "SUCCESS_MESSAGE" => "SMS успешно отправлено",
        "AJAX_MODE" => "Y",
    ]
);?>
```

## Параметры компонента

| Параметр | Тип | Описание | По умолчанию |
|----------|-----|----------|--------------|
| `API_LOGIN` | string | Логин SMSC.ru (обязательно) | - |
| `API_PASSWORD` | string | Пароль SMSC.ru (обязательно) | - |
| `SENDER_NAME` | string | Имя отправителя (опционально) | - |
| `SUCCESS_MESSAGE` | string | Сообщение об успешной отправке | SMS успешно отправлено |
| `AJAX_MODE` | string | Включить AJAX режим (Y/N) | Y |

## Основные возможности

### 1. POST-запрос к API

```php
use Bitrix\Main\Web\HttpClient;

$httpClient = new HttpClient([
    'socketTimeout' => 10,
    'streamTimeout' => 30,
]);

$params = [
    'login' => $login,
    'psw' => $password,
    'phones' => $phone,
    'mes' => $message,
    'fmt' => 3,  // JSON ответ
];

$url = self::API_URL . '?' . http_build_query($params);
$response = $httpClient->get($url);
```

### 2. Валидация номера телефона

```php
private function formatPhone($phone)
{
    // Убираем все кроме цифр и +
    $phone = preg_replace('/[^0-9+]/', '', $phone);
    
    // Заменяем 8 на +7
    if (strpos($phone, '8') === 0) {
        $phone = '+7' . substr($phone, 1);
    }
    
    return $phone;
}
```

### 3. AJAX-обработка формы

```javascript
fetch(window.location.href, {
    method: 'POST',
    body: formData,
    headers: {
        'X-Requested-With': 'XMLHttpRequest'
    }
})
.then(response => response.json())
.then(data => {
    if (data.success) {
        // Успех
    } else {
        // Ошибка
    }
});
```

### 4. Обработка ошибок API

```php
if (isset($data['error'])) {
    throw new \Exception($this->getErrorMessage($data['error'], $data['error_code']));
}
```

## Коды ошибок SMSC.ru

| Код | Описание |
|-----|----------|
| 1 | Ошибка в параметрах |
| 2 | Неверный логин или пароль |
| 3 | Недостаточно средств на счете |
| 4 | IP-адрес временно заблокирован |
| 5 | Неверный формат даты |
| 6 | Сообщение запрещено (стоп-лист) |
| 7 | Неверный формат номера телефона |
| 8 | Сообщение не может быть доставлено |
| 9 | Отправка дубликата (защита от повторов) |

## Логирование

Компонент логирует:

✅ **Запросы:**
- Номер телефона
- Длина сообщения
- Время отправки

✅ **Успешные ответы:**
- ID отправленного SMS
- Время выполнения запроса

✅ **Ошибки:**
- Текст ошибки
- Код ошибки API

❌ **НЕ логирует:**
- Пароль API
- Полный текст сообщения (только длина)

Логи находятся в: `/bitrix/admin/event_log.php`  
Префикс: `sms_sender`

## Стоимость SMS (SMSC.ru)

**По России:**
- От 3 рублей за SMS
- Скидки при больших объемах

**Тарифы зависят от:**
- Объема отправки
- Типа сообщения (обычное/рекламное)
- Наличия имени отправителя

## Безопасность

✅ **Реализовано:**
- Проверка сессии через `check_bitrix_sessid()`
- Валидация номера телефона

- Защита от повторной отправки (защита SMSC)

- Не храните логин/пароль в коде

## Частые вопросы

**Q: Почему SMS не отправляется?**  
A: Проверьте баланс на SMSC.ru и логи в `/bitrix/admin/event_log.php`

**Q: Можно ли использовать бесплатно?**  
A: Нет, все SMS-сервисы платные. SMSC дает тестовые SMS при регистрации.

**Q: Как зарегистрировать имя отправителя?**  
A: В личном кабинете SMSC.ru → "Имена отправителей" → заполните форму (проверка 1-3 дня)

**Q: Сколько символов в одном SMS?**  
A: 70 символов кириллицы или 160 латиницы. Длинные сообщения делятся на части.
