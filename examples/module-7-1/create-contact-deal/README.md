# Задача 1: Создание контакта с привязкой к компании и сделке

## Описание задачи

Создать PHP-скрипт, который через REST API Bitrix24:
1. Создает новую компанию (или находит существующую по названию)
2. Создает контакт с привязкой к этой компании
3. Открывает сделку и связывает её с компанией и контактом

## Бизнес-кейс

Типичная задача при интеграции с внешними системами: поступают данные о клиенте (из формы на сайте, из 1С, из таблицы Excel), и нужно автоматически создать полную цепочку сущностей в CRM.

## Что демонстрирует пример

- Проверка существования компании перед созданием (дедупликация)
- Создание связанных сущностей
- Обработка ошибок REST API
- Batch-запросы для оптимизации количества обращений к API

## Как использовать

### 1. Настройте подключение

Отредактируйте `config.php`:

```php
return [
    'domain' => 'your-portal.bitrix24.ru',
    'webhook' => 'your_webhook_code_here'
];
```

### 2. Запустите скрипт

```bash
php create_full_chain.php
```

### 3. Проверьте результат

В выводе вы увидите:
- ID созданной компании (или найденной существующей)
- ID созданного контакта
- ID созданной сделки

## Пример вывода

```
✅ Компания найдена: ID 123
✅ Контакт создан: ID 456
✅ Сделка создана: ID 789

Детали:
```

## Основные концепции

### 1. Дедупликация компаний

Перед созданием новой компании проверяем, не существует ли уже компания с таким названием:

```php
// Ищем компанию по названию
$existingCompany = $crm->findCompanyByTitle('ООО Рога и Копыта');

if ($existingCompany) {
    // Используем существующую
    $companyId = $existingCompany['ID'];
} else {
    // Создаем новую
    $companyId = $crm->createCompany([...]);
}
```

### 2. Связывание сущностей

Контакт связывается с компанией через поле `COMPANY_ID`:

```php
$contactId = $crm->createContact([
    'NAME' => 'Иван',
    'LAST_NAME' => 'Петров',
    'COMPANY_ID' => $companyId,  // Связь с компанией
    // ...
]);
```

Сделка связывается и с компанией, и с контактом:

```php
$dealId = $crm->createDeal([
    'TITLE' => 'Поставка оборудования',
    'COMPANY_ID' => $companyId,      // Связь с компанией
    'CONTACT_IDS' => [$contactId],   // Связь с контактом (массив)
    // ...
]);
```

### 3. Обработка ошибок

Каждый REST API запрос может вернуть ошибку. Важно правильно обрабатывать:

```php
if (isset($response['error'])) {
    throw new Exception("Ошибка создания сделки: " . $response['error_description']);
}
```

## Возможные ошибки

### Ошибка: "ERROR_CORE: Required fields: COMPANY_ID"

**Причина:** При создании сделки не указана компания или контакт

**Решение:** Убедитесь, что передается `COMPANY_ID` или `CONTACT_IDS`

### Ошибка: "ERROR_CORE: Access denied"

**Причина:** Webhook не имеет прав на создание сущностей CRM

**Решение:** Проверьте права webhook в настройках Bitrix24

### Ошибка: "ERROR_CORE: Invalid stage_id"

**Причина:** Указан неверный ID стадии сделки

**Решение:** Используйте корректный формат `C1:1`, `C1:2` и т.д.
