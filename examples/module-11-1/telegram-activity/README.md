# Пользовательское активити «Отправить Telegram-сообщение»

Робот/активити для Bitrix24, который отправляет сообщение в Telegram-чат через Bot API. Работает в конструкторе роботов и бизнес-процессов для сделок, лидов, контактов и компаний.

## Файлы

- `crest.php` — минимальный REST-клиент (вебхук-режим)
- `install.php` — регистрация активити через `bizproc.activity.add` (запускается **один раз**)
- `handler.php` — endpoint, который Битрикс24 вызывает при каждом срабатывании

## Установка

1. Получите токен бота у @BotFather в Telegram.
2. Впишите токен в `handler.php` (`$tgToken`).
3. В `crest.php` укажите ваш входящий вебхук `C_REST_WEB_HOOK_URL` с доступом `bizproc`, `crm`.
4. В `install.php` впишите реальный URL `handler.php` и ID пользователя (`AUTH_USER_ID`).
5. Откройте `install.php` в браузере → активити зарегистрирован.
6. В CRM: Сделка → Роботы → добавить робота «Telegram: отправить сообщение».

## Как это работает

1. БП/робот срабатывает → Битрикс24 шлёт POST на `handler.php` с `event_token`, `document_id`, `properties`.
2. Обработчик сразу отвечает `200 OK` и закрывает соединение (`fastcgi_finish_request`).
3. `bizproc.event.send` — подтверждает приём (БП ждёт).
4. Отправляем запрос в Telegram Bot API.
5. `bizproc.activity.completed` — завершаем активити, передаём `MESSAGE_ID`, `SENT_AT`, `STATUS` в `OUTPUT` — их можно использовать в следующих действиях БП.

## Отладка

- `activity.log` — все входящие запросы и результаты.
- Журнал БП в карточке сделки (Бизнес-процессы → Журнал) — видно `LOG_MESSAGE`.

## Ключевые моменты для собеседования

- Асинхронная схема: `event.send` → работа → `activity.completed`.
- `EVENT_TOKEN` связывает HTTP-вызов и конкретный экземпляр БП.
- `RETURN_PROPERTIES` должны совпадать с ключами `OUTPUT`.
- Лимит на ответ обработчика ~30 сек — долгие операции в фоне.
