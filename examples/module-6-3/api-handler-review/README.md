# Code Review #2: REST-эндпоинт повтора заказа

## Файлы

- `bad_api.php` — плохой код для разбора (7+ ошибок, включая IDOR)
- `good_api.php` — исправленная версия: мердж в корзину вместо клона заказа
- `review_analysis.md` — полный разбор

## Как работать

1. Прочитай `bad_api.php` — найди проблемы безопасности и логики.
2. Обрати внимание на главный архитектурный вопрос: «повтор» — это клон заказа или наполнение корзины?
3. Сравни с `good_api.php` и `review_analysis.md`.

## Что тренирует

- IDOR (самая частая находка на реальных ревью)
- Разница между «клонировать заказ» и «наполнить корзину для checkout»
- Идемпотентность (мердж вместо дублей)
- Безопасное логирование ошибок (детали в лог, не пользователю)
