# Code Review #1: Компонент списка заказов

## Файлы

- `bad_component.php` — плохой код для разбора (8+ ошибок)
- `good_component.php` — исправленная версия с комментариями
- `review_analysis.md` — полный разбор с таблицей проблем

## Как работать

1. Прочитай `bad_component.php` как ревьюер — найди все проблемы.
2. Запиши список: что, почему, как исправить.
3. Сравни с `review_analysis.md` — что пропустил?
4. Посмотри `good_component.php` — как исправлено.

## Что тренирует

- IDOR / авторизация
- N+1 и batch-запросы
- Кеширование (ключи, теги, `setResultCacheKeys`)
- Разделение бизнес-логики и представления
