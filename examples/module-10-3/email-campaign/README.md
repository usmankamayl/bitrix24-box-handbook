# Пример: Email-рассылка сегменту контактов (Bitrix24)

## Описание

Два скрипта демонстрируют полный цикл email-рассылки через REST API Bitrix24:

- **segment.php** — формирует сегмент: выбирает контакты, у которых за последние 6 месяцев была выигранная сделка, проверяет наличие email и черный список. Результат — `segment.json`.
- **send.php** — персонализированная массовая отправка через `crm.message.add` с использованием `batch` и макросов `#NAME#`, `#UNSUBSCRIBE_LINK#`.

## Установка

1. Создай **входящий вебхук** в Bitrix24:
   - Раздел "Разработчикам" → "Другое" → "Входящий вебхук"
   - Права: **CRM (crm)**
   - Скопируй URL вида `https://portal.bitrix24.ru/rest/1/XXX/`
2. Пропиши URL в `crest.php` → `CRest::WEBHOOK_URL`
3. Укажи свой почтовый ящик в `send.php` → `EMAIL_FROM`
   (должен быть подключён в CRM → Настройки → Почта)
4. Настрой `UNSUBSCRIBE_URL` — реальную страницу отписки

## Использование

```bash
# 1. Сформируй сегмент
php segment.php
# -> segment.json

# 2. Запусти отправку
php send.php
# -> send_log_YYYYMMDD_HHMMSS.json
```

## Что демонстрирует

| Приём | Где |
|-------|-----|
| Постраничная выборка `crm.deal.list` через `start`/`next` | segment.php, шаг 1 |
| Фильтр по стадии `WON` и дате `>=CLOSEDATE` | segment.php |
| `batch` для массовой загрузки контактов | segment.php, шаг 2 |
| Работа с multifield `EMAIL` (приоритет `MAILING`) | segment.php, шаг 3 |
| Проверка черного списка | segment.php |
| Персонализация шаблона макросами | send.php, `personalize()` |
| Массовая `crm.message.add` через `batch` | send.php |
| Паузы против rate limit | `usleep(500000)` |
| Логирование ошибок по каждой команде батча | send.php |

## Ограничения

- `crm.message.add` — транзакционные письма из карточки CRM. **Нет трекинга открытий/кликов, нет управления отписками.** Для полноценного маркетинга используй CRM-маркетинг Bitrix24 или внешний сервис (Unisender, Mailchimp).
- Rate limit: ~2 запроса/сек. Для тысяч писем нужна очередь через CRON.
- Ссылка отписки — обязательна по закону (152-ФЗ, GDPR, CAN-SPAM).

## Для собеседования

- Чем `crm.message.add` отличается от CRM-маркетинга
- Почему нельзя фильтровать `crm.contact.list` по полю `EMAIL` (multifield) и что делать вместо (`crm.duplicate.findbycomm`)
- Как `batch` снижает нагрузку на rate limit
- Как работает трекинг открытий (пиксель) и почему Apple MPP его ломает
- Что обязательно должно быть в маркетинговом письме (ссылка отписки)
