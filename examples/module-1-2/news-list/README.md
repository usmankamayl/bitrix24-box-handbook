# Пример 1: Компонент "Список новостей"

Полный пример создания компонента с использованием класса.

## Структура компонента

```
/local/components/custom/news.list/
├── .description.php        # Описание компонента
├── .parameters.php         # Параметры компонента
├── class.php              # Класс компонента (основная логика)
├── component.php          # Точка входа (при использовании class.php - пустой)
└── templates/
    └── .default/
        ├── template.php           # Шаблон отображения
        ├── result_modifier.php    # Модификация результата
        ├── style.css             # Стили
        └── script.js             # JavaScript
```

## Установка компонента

1. Скопируйте папку `news-list` в `/local/components/custom/`
2. Компонент появится в визуальном редакторе в разделе "Мои компоненты → Новости"

## Использование на странице

### Через PHP

```php
<?php
$APPLICATION->IncludeComponent(
    "custom:news.list",
    ".default",
    [
        "IBLOCK_ID" => 1,                    // ID инфоблока с новостями
        "COUNT" => 10,                       // Количество элементов
        "SORT_BY" => "ACTIVE_FROM",          // Поле сортировки
        "SORT_ORDER" => "DESC",              // Порядок сортировки
        "SHOW_PICTURE" => "Y",               // Показывать картинки
        "SHOW_DATE" => "Y",                  // Показывать дату
        "SHOW_PREVIEW_TEXT" => "Y",          // Показывать анонс
        "PREVIEW_TEXT_LENGTH" => 200,        // Длина анонса
        "CACHE_TYPE" => "A",                 // Автокеширование
        "CACHE_TIME" => 3600,                // Время кеша (1 час)
    ],
    false
);
?>
```

### Через визуальный редактор

1. В режиме редактирования страницы нажмите "Добавить компонент"
2. Найдите "Мои компоненты → Новости → Список новостей"
3. Настройте параметры через интерфейс
4. Сохраните

## Основные возможности

### 1. Гибкие параметры
- Выбор инфоблока
- Настройка количества элементов
- Сортировка по разным полям
- Управление отображением элементов

### 2. Кеширование
- Автоматическое кеширование результатов
- Умное прерывание кеша при пустом результате
- Поддержка кеширования в рамках (для ajax)

### 3. Адаптивный дизайн
- Мобильная версия
- Плавные анимации
- Hover-эффекты

### 4. Режим правки
- Редактирование элементов на сайте
- Кнопки "Редактировать" и "Удалить" в режиме правки

## Расширение функционала

### Добавление пагинации

В `class.php` измените метод `getElements()`:

```php
protected function getElements(): array
{
    // Настройка постраничной навигации
    $navParams = [
        "nPageSize" => $this->arParams["COUNT"],
        "bShowAll" => false,
    ];

    $rsElements = \CIBlockElement::GetList(
        $arOrder,
        $arFilter,
        false,
        $navParams,  // Вместо ["nTopCount" => $this->arParams["COUNT"]]
        $arSelect
    );

    // Сохраняем объект навигации
    $this->arResult["NAV_STRING"] = $rsElements->GetPageNavStringEx(
        $navComponentObject,
        "Новости",
        ".default",
        false
    );

    // ...остальной код
}
```

### Добавление фильтра по разделу

Добавьте в `.parameters.php`:

```php
"SECTION_ID" => [
    "PARENT" => "BASE",
    "NAME" => "ID раздела",
    "TYPE" => "STRING",
    "DEFAULT" => "",
],
```

В `class.php` в методе `getElements()`:

```php
$arFilter = [
    "IBLOCK_ID" => $this->arParams["IBLOCK_ID"],
    "ACTIVE" => "Y",
];

// Фильтр по разделу
if (!empty($this->arParams["SECTION_ID"])) {
    $arFilter["SECTION_ID"] = intval($this->arParams["SECTION_ID"]);
}
```

## Частые вопросы

**Q: Где хранится кеш компонента?**  
A: В `/bitrix/cache/` в зависимости от настроек кеширования

**Q: Как сбросить кеш компонента?**  
A: В админке: Настройки → Производительность → Очистить кеш

**Q: Можно ли использовать компонент ajax?**  
A: Да, благодаря `setFrameMode(true)` компонент поддерживает ajax-обновление

**Q: Как создать свой шаблон?**  
A: Скопируйте папку `.default` и переименуйте её, затем измените файлы внутри
