# Задача 2: Компонент со смешанным контентом

## Что показывает

**Статика:** список товаров — общий для всех пользователей, кешируется.

**Динамика:** кнопка "В избранное" — состояние зависит от пользователя, выносится в frame.

## Senior-фичи

1. **`$this->setFrameMode(true)`** — явное голосование компонента за composite. Без этого компонент может "проголосовать против" и вся страница станет динамической.

2. **Отделение статики от динамики** — `is_favorite` НЕ включается в SQL-запрос списка. Список общий, кнопки индивидуальные.

3. **Делегирование событий** — после composite-замены DOM обновляется, обработчики на удалённых элементах теряются. Делегируем на контейнер.

4. **`data-*` атрибуты** — для связи DOM ↔ JS без inline-обработчиков.

## Вопросы на собеседовании

- "Как сделать кнопку 'В избранное' в кешированном списке?" → frame + AJAX
- "Почему обработчик click не работает после composite-загрузки?" → DOM заменился, делегировать на родителя
