# Практика модуля 1.7 — контекст, Request, ответ

Проба контекста, четыре задачи по `Request` и контрольное задание. Каждая
папка — самостоятельный набор файлов, который копируется в демо-инсталляцию.
Примеры — для **коробки** (БУС или Bitrix24 Box); на облаке `/local/` нет, там
эндпоинты не разворачиваются.

| Папка | Что показывает | Что копировать |
|---|---|---|
| `task-context-probe/` | классы `Context`/`Request`, матрица методов, доказательство «Request — снимок» | `probe.php` → `/local/tools/context-probe.php` |
| `task-request/` | GET, POST-форма, JSON-эндпоинт, валидатор без HTTP | 4 файла по путям из `task-request/README.md` |
| `control-task/` | пять дефектов эндпоинта и эталон | ничего, только чтение |

Порядок: проба → `search.php` → `registration-form.php` →
`json-endpoint.php` → контрольное задание. Проба не обязательна для зачёта, но
она отвечает на все `[проверить]` из теории подраздела.

Все файлы проверены `php -l` (PHP 8.1; код совместим с 8.3). Запуск на живой
инсталляции — на стороне пользователя: локально ядро не поднимается.
