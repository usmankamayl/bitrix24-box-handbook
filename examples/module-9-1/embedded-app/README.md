# Пример: Встраиваемое приложение для Bitrix24

## Описание

Простое встраиваемое приложение, которое отображается внутри интерфейса Bitrix24 и показывает:
- Информацию о текущем пользователе
- Последние 5 лидов из CRM

## Как работает

1. Bitrix24 загружает `index.php` в iframe
2. Приложение получает `AUTH_ID` из параметров URL
3. Использует `BX24.js` для вызова REST API
4. Отображает данные в HTML

## Установка

### 1. Размести код на сервере с HTTPS

```bash
# Загрузи index.php на свой сервер
scp index.php user@your-server.com:/var/www/html/app/
```

### 2. Зарегистрируй приложение в Bitrix24

1. Перейди на https://dev.bitrix24.ru/marketplace/
2. Создай новое приложение:
   - **Тип:** Встраиваемое
   - **Menu URL:** `https://your-domain.com/app/index.php`
   - **Scope:** `crm,user`
3. Сохрани `CLIENT_ID` и `CLIENT_SECRET`

### 3. Установи на портал

1. В Bitrix24 перейди в "Приложения" → "Мои приложения"
2. Нажми "Добавить приложение"
3. Выбери свое приложение
4. После установки приложение появится в левом меню

## Что демонстрирует

- ✅ Получение `AUTH_ID` для доступа к REST API
- ✅ Вызов методов через `BX24.js`
- ✅ Отображение данных в iframe
- ✅ Работа с текущим пользователем
