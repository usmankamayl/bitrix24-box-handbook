# Задача 3: Загрузка и привязка файлов к сделке через пользовательское поле

## Описание задачи

Необходимо создать систему управления файлами для Сделок в Bitrix24 CRM:
- Создать пользовательское поле типа "файл" для хранения договоров
- Загружать файлы в формате Base64 через REST API
- Поддерживать множественную загрузку файлов
- Скачивать прикрепленные файлы
- Удалять ненужные файлы

## Цель

Научиться:
- Создавать пользовательские поля типа `file`
- Кодировать файлы в Base64 для передачи через REST API
- Загружать файлы при создании/обновлении сделки
- Получать информацию о прикрепленных файлах
- Скачивать файлы обратно
- Удалять файлы из множественного поля

## Особенности работы с файлами

### Формат загрузки
Файлы передаются как массив: `["имя_файла", "base64_содержимое"]`

### Множественная загрузка
```php
"UF_CRM_DOCUMENTS": [
    ["doc1.pdf", base64_encode($content1)],
    ["doc2.pdf", base64_encode($content2)]
]
```

### Получение файла
API возвращает ID файла, затем можно скачать через `/disk.file.get`

## Решение

### Файлы:
- `DealFileManager.php` — класс для управления файлами сделок
- `example-files/` — примеры файлов для тестирования

## Использование

```php
// Создаем менеджер
$manager = new DealFileManager($apiUrl, $accessToken);

// Создаем поле для файлов
$manager->createFileField();

// Загружаем файл
$manager->uploadFile($dealId, 'contract.pdf', '/path/to/contract.pdf');

// Загружаем несколько файлов
$manager->uploadMultipleFiles($dealId, [
    'contract.pdf' => '/path/to/contract.pdf',
    'invoice.pdf' => '/path/to/invoice.pdf'
]);

// Получаем список файлов
$files = $manager->getFiles($dealId);

// Скачиваем файл
$manager->downloadFile($fileId, '/path/to/save/contract.pdf');

// Удаляем файл
$manager->deleteFile($dealId, $fileId);
```

## Важные моменты

1. **Base64 кодирование:** файлы должны быть закодированы в Base64 перед отправкой
2. **Размер файлов:** учитывайте лимиты API на размер запроса
3. **Множественное поле:** при обновлении нужно включать все файлы (старые + новые)
4. **ID файла:** используется для скачивания и удаления

## Ограничения

- Размер файла: до 50 МБ (зависит от настроек портала)
- Формат передачи: Base64 (увеличивает размер ~на 33%)
- При большом количестве файлов загружайте по одному

## Ожидаемый результат

- Можно загружать PDF, DOC, изображения и другие файлы
- Файлы хранятся на Битрикс24 и доступны для скачивания
- Возможно управлять файлами (добавление, удаление)
