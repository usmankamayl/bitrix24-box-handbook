# Задача 1: Добавление пользовательского поля "Источник лида" с выпадающим списком

## Описание задачи

Необходимо создать пользовательское поле для **Лидов** с именем "Источник лида", которое будет содержать выпадающий список возможных источников:
- Google Ads
- Яндекс.Директ
- Facebook
- Instagram
- Сайт (органика)
- Рекомендация

## Цель

Научиться:
- Создавать пользовательские поля через REST API
- Работать с типом `enumeration` (выпадающий список)
- Получать метаданные полей
- Устанавливать значения списка при создании лида

## Решение

### Файлы:
- `create-field.php` — создание пользовательского поля
- `set-value.php` — установка значения при создании лида
- `get-fields.php` — получение метаданных полей

## Использование

### 1. Создание поля
```bash
php create-field.php
```

### 2. Создание лида с заполненным полем
```bash
php set-value.php
```

### 3. Получение метаданных полей лида
```bash
php get-fields.php
```

## Что демонстрирует пример

✅ Создание пользовательского поля типа `enumeration`  
✅ Установка списка значений с сортировкой  
✅ Получение ID значения списка  
✅ Установка значения при создании сущности  
✅ Кеширование метаданных полей  

## Важные моменты

1. **Префикс поля:** `UF_CRM_` обязателен для пользовательских полей CRM
2. **ID значения списка:** при установке значения передается ID элемента, а не текст
3. **SORT:** определяет порядок отображения в списке
4. **Кеширование:** метаданные полей меняются редко, их можно кешировать

## Ожидаемый результат

После выполнения скриптов в Bitrix24:
- В карточке Лида появится поле "Источник лида"
- Поле будет содержать выпадающий список из 6 значений
- При создании нового лида можно выбрать источник
- Значение сохраняется и доступно для фильтрации
