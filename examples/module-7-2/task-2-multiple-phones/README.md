# Задача 2: Управление множественными телефонами контакта (добавление, обновление, удаление)

## Описание задачи

Необходимо создать класс для управления множественными телефонами контакта в Bitrix24 CRM. Система должна поддерживать:
- **Добавление** новых телефонов без удаления существующих
- **Обновление** конкретного телефона по ID
- **Удаление** отдельного телефона
- **Получение** всех телефонов контакта

## Цель

Научиться:
- Работать с множественными полями в Bitrix24
- Правильно добавлять значения в существующее множественное поле (не потеряв старые)
- Получать и парсить структуру множественных полей
- Выполнять операции обновления, добавления, удаления для множественных значений

## Проблема

❌ **Частая ошибка:**
При обновлении контакта забывают включить существующие телефоны → они удаляются!

```php
// ❌ ПЛОХО: второй телефон удалится
POST /crm.contact.update
{
    "id": 123,
    "fields": {
        "PHONE": [
            {"VALUE": "+79993334455", "VALUE_TYPE": "MOBILE"}
        ]
    }
}
```

✅ **Правильный подход:**
1. Читаем текущие телефоны
2. Модифицируем массив
3. Отправляем полный массив (все старые + новые)

## Решение

### Файлы:
- `ContactPhoneManager.php` — класс для управления телефонами
- `examples.php` — примеры использования

## Использование

```php
// Создаем менеджер
$manager = new ContactPhoneManager($apiUrl, $accessToken);

// Получаем все телефоны контакта
$phones = $manager->getPhones($contactId);

// Добавляем новый телефон
$manager->addPhone($contactId, '+79991234567', 'WORK');

// Обновляем телефон
$manager->updatePhone($contactId, $phoneId, '+79999999999', 'MOBILE');

// Удаляем телефон
$manager->deletePhone($contactId, $phoneId);
```

## Что демонстрирует пример

✅ Получение множественного поля с его структурой  
✅ Корректное добавление нового значения без потери существующих  
✅ Обновление отдельного значения по ID  
✅ Удаление конкретного значения из множественного поля  
✅ Валидация данных перед отправкой  
✅ Обработка ошибок API  

## Важные моменты

1. **Порядок операций:** ВСЕГДА читай → модифицируй → записывай
2. **ID значения:** используется для идентификации при обновлении/удалении
3. **VALUE_TYPE:** определяет категорию (WORK, MOBILE, HOME, OTHER)
4. **Полная замена:** если не включить старое значение, оно удалится

## Типы телефонов (VALUE_TYPE)

- `WORK` — рабочий телефон
- `MOBILE` — мобильный телефон
- `HOME` — домашний телефон
- `OTHER` — другой телефон

## Ожидаемый результат

После выполнения примеров:
- Контакт имеет несколько телефонов
- Каждый телефон обозначен типом (WORK, MOBILE и т.д.)
- Возможно добавлять, обновлять, удалять телефоны без потери данных
