# Задача 3: Диагностика "медленной страницы"

## Что делает скрипт

Полный пайплайн диагностики производительности:

1. **Замер общего времени** — CLI-запуск без браузера
2. **Разделение PHP/MySQL** — где проблема: код или БД
3. **N+1 детектор** — повторяющиеся запросы
4. **Топ медленных запросов** — для EXPLAIN
5. **Проверка кеша** — cold vs warm сравнение
6. **Чеклист диагнозов** — типичные проблемы

## Как использовать

```bash
php debug-slow-page.php
# Отредактируй $_SERVER['REQUEST_URI'] под нужную страницу
```

## Типичные находки

| Симптом | Диагноз | Решение |
|---------|---------|---------|
| `PHP: 7s, MySQL: 0.5s` | Код — циклы, файлы | XHProf → находим узкое место |
| `[50x] SELECT ... WHERE ID=?` | N+1 | `->with('USER')` в ORM |
| `SELECT * FROM b_iblock_element LIMIT 100000,20` | Нет индекса + filesort | `ADD INDEX (IBLOCK_ID, ACTIVE, SORT)` |
| Warm == Cold | Кеш не работает | Проверить CACHE_TYPE, composite голосование |
| `curl` в логах > 1s | Внешнее API тормозит | Кешировать или делать асинхронно |
