# Задача 2: Импорт контактов из CSV с batch

## 📝 Описание

Создать класс для массового импорта контактов из CSV-файла с использованием batch-запросов. Включает проверку дублей, нормализацию данных и детальное логирование процесса.

## 🔑 Ключевые концепции

1. Чтение и парсинг CSV-файлов
2. Валидация и нормализация данных (телефоны, email)
3. Проверка дублей по телефону/email
4. Batch-создание контактов
5. Обработка ошибок и конфликтов
6. Детальное логирование результатов

## 💡 Когда использовать

- Импорт базы контактов из внешних систем
- Миграция данных в Bitrix24
- Массовая загрузка участников мероприятия
- Синхронизация с 1C или другими CRM

## 📖 README

**Расположение:** `/local/php_interface/classes/ContactBatchImporter.php`

**Использование:**
```php
$importer = new \Vettich\ContactBatchImporter($client);

// Импорт из CSV
$result = $importer->importFromCsv('/path/to/contacts.csv', [
    'skip_duplicates' => true,      // Пропускать дубли
    'update_duplicates' => false,   // Обновлять существующие
    'normalize_phones' => true      // Нормализовать телефоны
]);

// Получить отчет
$report = $importer->getReport();
```

**Формат CSV:**
```csv
name,phone,email,company,position
Иван Иванов,89001234567,ivan@example.com,ООО Компания,Директор
Петр Петров,+79001234568,petr@example.com,ИП Петров,ИП
```

**Возвращаемые данные:**
- Количество импортированных контактов
- Количество пропущенных дублей
- Количество ошибок
- Детальный лог операций
