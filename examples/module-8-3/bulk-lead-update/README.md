# Задача 1: Массовое обновление лидов в batch

## 📝 Описание

Создать класс для массового обновления статуса лидов с использованием batch-запросов. Получить список лидов определенной воронки, обновить их статус и отследить прогресс.

## 🔑 Ключевые концепции

1. Получение больших списков лидов с помощью batch
2. Форматирование batch-запросов для обновления
3. Обработка результатов и ошибок
4. Логирование и отслеживание прогресса
5. Оптимизация размера пакета

## 💡 Когда использовать

- Массовая смена статуса лидов (например, перевод в архив)
- Обновление пользовательских полей для большого количества лидов
- Синхронизация данных из внешней системы
- Очистка базы от неактивных лидов

## 📖 README

**Расположение:** `/local/php_interface/classes/LeadBatchUpdater.php`

**Использование:**
```php
$updater = new \Vettich\LeadBatchUpdater($client);

// Обновить все лиды определенного статуса в активные
$updater->updateLeadStatusByFilter([
    'STATUS_ID' => 'NEW',
    'DATE_CREATE' => ['<' => '2024-01-01']
], 'IN_PROCESS');

// Обновить конкретные лиды
$updater->updateLeads([123, 456, 789], [
    'STATUS_ID' => 'CONVERTED',
    'ASSIGNED_BY_ID' => 1
]);

// Получить отчет
$report = $updater->getReport();
```

**Возвращаемые данные:**
- Количество успешно обновленных лидов
- Количество ошибок
- Время выполнения
- Список ошибок (если были)
