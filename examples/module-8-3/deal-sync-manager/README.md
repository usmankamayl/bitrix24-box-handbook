# Задача 3: Синхронизация сделок между системами через batch

## 📝 Описание

Создать класс для синхронизации сделок между Bitrix24 и внешней системой (например, 1C или другой CRM) с использованием batch-запросов. Включает получение сделок, преобразование данных, отправку обновлений и откат при ошибках.

## 🔑 Ключевые концепции

1. Получение списка сделок через batch
2. Преобразование данных между форматами систем
3. Отправка обновлений в batch-режиме
4. Обработка ошибок и конфликтов
5. Механизм отката при критических ошибках
6. Синхронизация в обе стороны

## 💡 Когда использовать

- Интеграция с 1C
- Синхронизация с другими CRM-системами
- Обновление внешних баз данных на основе изменений в Bitrix24
- Выгрузка отчетов в аналитические системы
- Синхронизация с системами оплаты

## 📖 README

**Расположение:** `/local/php_interface/classes/DealSyncManager.php`

**Использование:**
```php
$sync = new \Vettich\DealSyncManager($client, $externalApi);

// Синхронизация новых/измененных сделок
$result = $sync->syncModifiedDeals([
    'since' => '-7 days',           // Сделки за последние 7 дней
    'external_system' => 'bitrix24_1c',
    'rollback_on_error' => true     // Откат при критических ошибках
]);

// Синхронизация по фильтру
$sync->syncByFilter(['STAGE_ID' => 'CONVERTED'], [
    'map_stage' => true,            // Маппировать стадии
    'sync_documents' => true        // Синхронизировать документы
]);

// Получить статус синхронизации
$status = $sync->getSyncStatus();
```

**Возвращаемые данные:**
- Количество синхронизированных сделок
- Количество конфликтов
- Количество ошибок
- Статус отката (если был выполнен)
