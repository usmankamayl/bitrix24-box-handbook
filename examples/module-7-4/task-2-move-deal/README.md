# Задача 2: Автоматическое перемещение сделки по воронке

## 📋 Описание

Реализация системы автоматического перемещения сделки по воронке продаж с учетом текущей стадии, проверкой возможности перехода и детальным логированием.

## 🎯 Цель

Научиться:
- Получать информацию о сделке и её текущей стадии
- Определять последовательность стадий в воронке
- Перемещать сделку на следующую/предыдущую стадию
- Валидировать переходы между стадиями
- Логировать все операции

## 🏗️ Структура кода

### Класс DealStageManager

Основной класс для работы со стадиями сделки.

#### Методы:

1. **moveToNextStage()** — переместить на следующую стадию
2. **moveToStage($targetStageId)** — переместить на конкретную стадию
3. **moveToPreviousStage()** — откатить на предыдущую стадию
4. **getStageHistory()** — получить историю перемещений
5. **printLogs()** — вывести лог операций

## 🚀 Использование

### 1. Создание объекта менеджера

```php
$manager = new DealStageManager($dealId);
```

### 2. Перемещение на следующую стадию

```php
$result = $manager->moveToNextStage();

if ($result['success']) {
    echo "Было: " . $result['previousStage'];
    echo "Стало: " . $result['currentStage'];
} else {
    echo "Ошибка: " . $result['error'];
}

$manager->printLogs();
```

### 3. Перемещение на конкретную стадию

```php
$result = $manager->moveToStage('C0:WON');

if ($result['success']) {
    echo "Сделка перемещена в: " . $result['currentStage'];
} else {
    echo "Ошибка: " . $result['error'];
}
```

### 4. Откат на предыдущую стадию

```php
$result = $manager->moveToPreviousStage();

if ($result['success']) {
    echo "Откачено на: " . $result['currentStage'];
} else {
    echo "Ошибка: " . $result['error'];
}
```

### 5. Получение истории перемещений

```php
$history = $manager->getStageHistory();

foreach ($history['history'] as $entry) {
    echo $entry['TITLE'] . "\n";
}
```

## 🔍 Ключевые концепции

### 1. Алгоритм перемещения на следующую стадию

```
1. Получить текущую сделку
2. Проверить, не на финальной ли стадии (success/failure)
3. Получить все стадии воронки
4. Отсортировать по SORT
5. Найти текущую стадию в списке
6. Взять следующую стадию
7. Переместить сделку
```

### 2. Семантика стадии

```php
'P' → process  (рабочая)
'S' → success  (успех)
'F' → failure  (провал)
```

Из финальной стадии (S или F) нельзя переместить сделку!

### 3. Валидация переходов

Перед перемещением проверяются:
- ✅ Не финальная ли текущая стадия
- ✅ Существует ли целевая стадия
- ⚠️ Логичен ли переход (например, прямой переход в провал)

### 4. Логирование

Все операции логируются с типом и временем:

```
✅ [2024-01-15 10:30:45] Сделка перемещена: C0:NEW → C0:PREPARATION
ℹ️  [2024-01-15 10:30:46] Текущая стадия: C0:PREPARATION
```

## 📊 Примеры

### Пример 1: Простое перемещение

```php
$manager = new DealStageManager(123);

// Переместить на следующую стадию
$result = $manager->moveToNextStage();

if ($result['success']) {
    echo "Успешно перемещено!";
} else {
    echo "Ошибка: " . $result['error'];
}

$manager->printLogs();
```

**Результат:**
```
✅ [2024-01-15 10:30:45] Текущая стадия: C0:NEW
ℹ️  [2024-01-15 10:30:46] Следующая стадия: C0:PREPARATION
✅ [2024-01-15 10:30:47] Сделка перемещена: C0:NEW → C0:PREPARATION
```

### Пример 2: Валидация перехода

```php
$manager = new DealStageManager(123);

// Попытка переместить на финальную стадию
$result = $manager->moveToStage('C0:LOSE');

if (!$result['success']) {
    echo "Ошибка: " . $result['error'];
}

// Проверка валидации
if (isset($result['validation']['warning'])) {
    echo "⚠️ Внимание: " . $result['validation']['reason'];
}
```

### Пример 3: Откат

```php
$manager = new DealStageManager(123);

// Если сделка на стадии PREPARATION, откатиться на NEW
$result = $manager->moveToPreviousStage();

echo "Откачено с: " . $result['previousStage'];
echo "Откачено на: " . $result['currentStage'];
```

## 🔧 Расширение функционала

### Добавить проверку перед перемещением

```php
public function moveToNextStageIfReady($dealId)
{
    // Проверить, готова ли сделка
    $deal = $this->getDeal($dealId);
    
    if (!$deal['OPPORTUNITY'] > 0) {
        return [
            'success' => false,
            'error' => 'Сумма не указана'
        ];
    }
    
    return $this->moveToNextStage();
}
```

### Добавить автоматическое перемещение по триггерам

```php
public function autoMoveOnEvent($eventType)
{
    switch($eventType) {
        case 'PAYMENT_RECEIVED':
            return $this->moveToStage('C0:PAYMENT_RECEIVED');
        case 'DOCUMENT_SIGNED':
            return $this->moveToStage('C0:SIGNED');
        default:
            return ['success' => false, 'error' => 'Unknown event'];
    }
}
```

## ⚠️ Важные замечания

1. **Финальные стадии** — из них нельзя переместить сделку, только создать новую
2. **SORT** — стадии отсортированы по этому полю, используется для определения порядка
3. **Семантика** — определяет тип стадии и влияет на логику перемещения
4. **История** — все перемещения автоматически сохраняются в timeline
5. **Откат** — нельзя откатиться с первой стадии

## 🐛 Возможные ошибки

### "Сделка не найдена"

**Причина**: ID сделки неверный или сделка была удалена

**Решение**: Проверьте ID сделки в CRM

### "Следующая стадия не найдена"

**Причина**: Сделка на последней стадии

**Решение**: Используйте `moveToStage()` для явного перемещения на нужную стадию

### "Нельзя перемещать из финальной стадии"

**Причина**: Сделка на стадии "успех" или "провал"

**Решение**: Используйте `getStageHistory()` для просмотра истории
