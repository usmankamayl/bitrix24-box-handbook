# Задача 3: Отчет по конверсии воронки продаж

## 📋 Описание

Создание детального отчета по воронке продаж с подсчетом количества сделок на каждой стадии, расчетом конверсии между стадиями, визуализацией в консоли и экспортом в CSV.

## 🎯 Цель

Научиться:
- Собирать статистику по стадиям воронки
- Рассчитывать конверсию между стадиями
- Определять узкие места в воронке продаж
- Создавать визуальные отчеты в консоли
- Экспортировать данные в CSV для дальнейшего анализа
- Сравнивать эффективность воронки за разные периоды

## 🏗️ Структура отчета

### Основной отчет содержит:

1. **Статистика по стадиям:**
   - Название стадии
   - Количество сделок
   - Общая сумма сделок
   - Конверсия в следующую стадию

2. **Общая конверсия воронки:**
   - От первой стадии до успешного завершения
   - Визуальная полоска прогресса

3. **Экспорт в CSV:**
   - Все данные в табличном формате
   - Корректная кодировка для Excel

## 🔍 Ключевые метрики

### 1. Конверсия между стадиями

```php
Конверсия = (Кол-во на след. стадии / Кол-во на текущей) * 100%
```

Показывает, какой процент сделок переходит с одной стадии на следующую.

**Пример:**
- Стадия "Новая": 150 сделок
- Стадия "Подготовка": 100 сделок
- Конверсия: 100 / 150 * 100% = 66.67%

### 2. Общая конверсия воронки

```php
Общая конверсия = (Успешные сделки / Все сделки в начале) * 100%
```

Показывает, какой процент сделок от начальной стадии доходит до успеха.

**Пример:**
- Начало воронки: 150 сделок
- Успешно завершено: 50 сделок
- Общая конверсия: 50 / 150 * 100% = 33.33%

### 3. Узкое место воронки

Стадия с **наименьшей конверсией** — это узкое место, где теряется больше всего клиентов.

## 📈 Интерпретация результатов

### Хорошие показатели:

- ✅ Конверсия между стадиями > 60%
- ✅ Общая конверсия воронки > 25%
- ✅ Равномерное распределение конверсии

### Проблемные показатели:

- ⚠️ Конверсия < 40% — серьезное узкое место
- ⚠️ Резкое падение на одной стадии
- ⚠️ Большое количество в "Провалено"

## 🔧 Расширение функционала

### 1. Фильтр по ответственному

```php
private function getDealsCountOnStage($stageId, $assignedById = null)
{
    $filter = [
        'CATEGORY_ID' => $this->categoryId,
        'STAGE_ID' => $stageId,
        '>=BEGINDATE' => $this->dateFrom,
        '<=BEGINDATE' => $this->dateTo . ' 23:59:59'
    ];
    
    if ($assignedById) {
        $filter['ASSIGNED_BY_ID'] = $assignedById;
    }
    
    $result = CRest::call('crm.deal.list', [
        'filter' => $filter,
        'select' => ['ID']
    ]);
    
    return isset($result['result']) ? count($result['result']) : 0;
}
```

### 2. Расчет среднего времени на стадии

```php
public function calculateAverageTimeOnStage($stageId)
{
    $deals = CRest::call('crm.deal.list', [
        'filter' => ['STAGE_ID' => $stageId],
        'select' => ['ID', 'BEGINDATE', 'CLOSEDATE']
    ]);
    
    $totalDays = 0;
    $count = 0;
    
    foreach ($deals['result'] as $deal) {
        if ($deal['BEGINDATE'] && $deal['CLOSEDATE']) {
            $begin = strtotime($deal['BEGINDATE']);
            $close = strtotime($deal['CLOSEDATE']);
            $totalDays += ($close - $begin) / 86400; // секунды в дни
            $count++;
        }
    }
    
    return $count > 0 ? round($totalDays / $count, 1) : 0;
}
```

### 3. Экспорт в JSON

```php
public function exportToJSON($statistics, $filename = null)
{
    $filename = $filename ?? __DIR__ . '/funnel_report_' . date('Y-m-d_H-i-s') . '.json';
    
    $data = [
        'funnel' => $this->getFunnelInfo(),
        'period' => [
            'from' => $this->dateFrom,
            'to' => $this->dateTo
        ],
        'statistics' => $statistics,
        'generatedAt' => date('Y-m-d H:i:s')
    ];
    
    file_put_contents($filename, json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE));
    
    return $filename;
}
```

## ⚠️ Важные замечания

1. **Фильтр по датам** — используется `BEGINDATE` (дата создания сделки), не путать с `CLOSEDATE`

2. **Большие воронки** — при большом количестве сделок используйте пагинацию:

```php
$start = 0;
$allDeals = [];

do {
    $result = CRest::call('crm.deal.list', [
        'filter' => [...],
        'start' => $start
    ]);
    
    $allDeals = array_merge($allDeals, $result['result']);
    $start += 50;
} while (isset($result['next']));
```

3. **Конверсия финальных стадий** — у стадий "Успех" и "Провал" конверсия не рассчитывается

4. **Сравнение периодов** — убедитесь, что периоды одинаковой длины для корректного сравнения

## 🐛 Возможные ошибки

### "Воронка не найдена"

**Причина**: Неверный ID воронки

**Решение**: Проверьте ID через `crm.dealcategory.list`

### Пустой отчет (0 сделок на всех стадиях)

**Причина**: Сделки созданы за пределами указанного периода

**Решение**: Расширьте период или уберите фильтр по датам для проверки

### Некорректная кодировка в CSV

**Причина**: Отсутствует BOM

**Решение**: Убедитесь, что в начало файла записывается BOM (уже реализовано в коде)
