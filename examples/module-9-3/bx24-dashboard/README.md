# Пример: CRM Дашборд на BX24.js

## Описание

Встраиваемое приложение — дашборд, демонстрирующий основные возможности **BX24.js**:

- `callBatch` — 4 счётчика сущностей одним запросом
- `callMethod` — список последних сделок
- `showPrompt` + `showNotification` — создание задачи
- `selectUser` — выбор пользователя
- `openPath` — навигация по порталу
- `fitWindow` — подгонка размера iframe

## Установка

1. Размести `index.html` на HTTPS-сервере
2. Зарегистрируй встраиваемое приложение на dev.bitrix24.ru:
   - **Menu URL:** `https://your-domain.com/module-9-3/bx24-dashboard/index.html`
   - **Scope:** `crm,task,user`
3. Установи на портал — приложение появится в левом меню

## Что демонстрирует

| Метод | Где используется |
|-------|------------------|
| `BX24.callBatch` | Счётчики лидов/сделок/контактов/компаний |
| `BX24.callMethod` | Загрузка сделок, создание задачи |
| `BX24.showPrompt` | Ввод названия задачи |
| `BX24.showNotification` | Уведомление об успехе/ошибке |
| `BX24.selectUser` | Выбор пользователя через диалог |
| `BX24.openPath` | Переход в списки и карточку сделки |
| `BX24.fitWindow` | Автовысота iframe |

## Для собеседования

- Чем `callBatch` быстрее 4 отдельных `callMethod`
- Почему весь код внутри `BX24.init()`
- Как `result.total()` и `result.data()` отличаются
