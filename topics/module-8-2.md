# Модуль 8.2: Методы CRM REST API

## Теория

### Основные сущности CRM

Bitrix24 CRM работает с несколькими основными типами сущностей:

1. **Лиды (Lead)** - потенциальные клиенты
2. **Сделки (Deal)** - активные продажи
3. **Контакты (Contact)** - физические лица
4. **Компании (Company)** - юридические лица
5. **Счета (Invoice)** - выставленные счета
6. **Предложения (Quote)** - коммерческие предложения

### Структура методов CRM

Все методы CRM следуют единой схеме именования:
```
crm.<entity>.<action>
```

**Примеры:**
- `crm.lead.add` - создать лид
- `crm.deal.update` - обновить сделку
- `crm.contact.get` - получить контакт
- `crm.company.list` - список компаний

## 1. Методы работы с Лидами (crm.lead.*)

### Основные методы

#### crm.lead.add
Создание нового лида.

**Параметры:**
```php
[
    'fields' => [
        'TITLE' => 'Название лида',
        'NAME' => 'Имя',
        'LAST_NAME' => 'Фамилия',
        'STATUS_ID' => 'NEW',           // Статус
        'OPENED' => 'Y',                 // Доступен всем
        'ASSIGNED_BY_ID' => 1,           // Ответственный
        'PHONE' => [
            ['VALUE' => '+7 (999) 123-45-67', 'VALUE_TYPE' => 'WORK']
        ],
        'EMAIL' => [
            ['VALUE' => 'test@example.com', 'VALUE_TYPE' => 'WORK']
        ]
    ]
]
```

**Ответ:**
```json
{
    "result": 123,
    "time": {...}
}
```

#### crm.lead.update
Обновление существующего лида.

**Параметры:**
```php
[
    'id' => 123,
    'fields' => [
        'TITLE' => 'Новое название',
        'STATUS_ID' => 'IN_PROCESS'
    ]
]
```

#### crm.lead.get
Получение лида по ID.

**Параметры:**
```php
[
    'id' => 123
]
```

**Ответ:**
```json
{
    "result": {
        "ID": "123",
        "TITLE": "Название лида",
        "NAME": "Имя",
        "LAST_NAME": "Фамилия",
        "STATUS_ID": "NEW",
        "DATE_CREATE": "2024-01-15T10:30:00+03:00",
        "PHONE": [
            {"ID": "456", "VALUE": "+7 (999) 123-45-67", "VALUE_TYPE": "WORK"}
        ]
    }
}
```

#### crm.lead.list
Получение списка лидов с фильтрацией.

**Параметры:**
```php
[
    'filter' => [
        'STATUS_ID' => 'NEW',
        '>DATE_CREATE' => '2024-01-01'
    ],
    'select' => ['ID', 'TITLE', 'NAME', 'STATUS_ID'],
    'order' => ['DATE_CREATE' => 'DESC'],
    'start' => 0
]
```

#### crm.lead.delete
Удаление лида.

**Параметры:**
```php
[
    'id' => 123
]
```

### Поля лида (основные)

| Поле | Тип | Описание |
|------|-----|----------|
| `ID` | integer | ID лида (только чтение) |
| `TITLE` | string | Название |
| `NAME` | string | Имя |
| `LAST_NAME` | string | Фамилия |
| `SECOND_NAME` | string | Отчество |
| `STATUS_ID` | string | Статус (NEW, IN_PROCESS, CONVERTED, JUNK) |
| `SOURCE_ID` | string | Источник (CALL, EMAIL, WEB, ADVERTISING) |
| `ASSIGNED_BY_ID` | integer | Ответственный (ID пользователя) |
| `CURRENCY_ID` | string | Валюта |
| `OPPORTUNITY` | double | Сумма |
| `OPENED` | char | Доступен для всех (Y/N) |
| `COMMENTS` | text | Комментарий |
| `DATE_CREATE` | datetime | Дата создания |
| `DATE_MODIFY` | datetime | Дата изменения |
| `PHONE` | crm_multifield | Телефоны (множественное поле) |
| `EMAIL` | crm_multifield | Email (множественное поле) |

Создание новой сделки.

```php
[
    'fields' => [
        'TITLE' => 'Продажа CRM',

        'STAGE_ID' => 'NEW',             // Стадия
        'OPPORTUNITY' => 50000,          // Сумма
        'CURRENCY_ID' => 'RUB',
        'ASSIGNED_BY_ID' => 1,

    ]

```

#### crm.deal.update
Обновление сделки.

#### crm.deal.get
Получение сделки по ID.

Список сделок с фильтрацией.

**Пример фильтра:**
```php
[
    'filter' => [
        'STAGE_ID' => 'NEW',
        '>=OPPORTUNITY' => 10000,

    ],
    'select' => ['ID', 'TITLE', 'STAGE_ID', 'OPPORTUNITY']
]
```

| Поле | Тип | Описание |
|------|-----|----------|
| `ID` | integer | ID сделки |
| `TITLE` | string | Название |
| `TYPE_ID` | string | Тип (SALE, SERVICES) |
| `STAGE_ID` | string | Стадия воронки |
| `PROBABILITY` | integer | Вероятность (%) |
| `CURRENCY_ID` | string | Валюта |
| `OPPORTUNITY` | double | Сумма |
| `ASSIGNED_BY_ID` | integer | Ответственный |
| `CONTACT_ID` | integer | Контакт |
| `COMPANY_ID` | integer | Компания |
| `BEGINDATE` | date | Дата начала |
| `CLOSEDATE` | date | Дата завершения |
| `CLOSED` | char | Сделка закрыта (Y/N) |

## 4. Работа с множественными полями

### Структура множественных полей

Телефоны, email, сайты хранятся как массив объектов:

```php
'PHONE' => [
    [
        'VALUE' => '+7 (999) 123-45-67',
        'VALUE_TYPE' => 'WORK'           // WORK, MOBILE, HOME, FAX
    ],
    [
        'VALUE' => '+7 (999) 987-65-43',
        'VALUE_TYPE' => 'MOBILE'
    ]
]
```

### Типы полей

**Телефоны (PHONE):**
- `WORK` - рабочий
- `MOBILE` - мобильный
- `FAX` - факс
- `HOME` - домашний
- `PAGER` - пейджер
- `OTHER` - другой

**Email (EMAIL):**
- `WORK` - рабочий
- `MAILING` - для рассылок
- `OTHER` - другой

**Сайты (WEB):**
- `WORK` - рабочий
- `HOME` - домашний
- `FACEBOOK` - Facebook
- `LIVEJOURNAL` - LiveJournal
- `OTHER` - другой

### Обновление множественных полей

При обновлении нужно передавать полный массив:

```php
// Заменит ВСЕ телефоны на новые
'PHONE' => [
    ['VALUE' => '+7 (999) 111-11-11', 'VALUE_TYPE' => 'WORK']
]
```

Чтобы добавить/изменить конкретный телефон, нужно:
1. Получить текущие данные через `get`
2. Изменить нужный элемент массива
3. Отправить полный массив через `update`

## 5. Фильтрация и сортировка

### Операторы фильтрации

| Оператор | Описание | Пример |
|----------|----------|--------|
| `=` | Равно (по умолчанию) | `'STATUS_ID' => 'NEW'` |
| `!=` | Не равно | `'!STATUS_ID' => 'JUNK'` |
| `>` | Больше | `'>OPPORTUNITY' => 10000` |
| `<` | Меньше | `'<OPPORTUNITY' => 50000` |
| `>=` | Больше или равно | `'>=DATE_CREATE' => '2024-01-01'` |
| `<=` | Меньше или равно | `'<=DATE_CREATE' => '2024-12-31'` |
| `%` | LIKE | `'%TITLE' => 'CRM'` |
| `=%` | LIKE в начале | `'=%TITLE' => 'CRM%'` |

### Примеры фильтрации

**Поиск лидов с телефоном:**
```php
'filter' => [
    '!PHONE' => false  // Телефон не пустой
]
```

**Диапазон дат:**
```php
'filter' => [
    '>=DATE_CREATE' => '2024-01-01T00:00:00',
    '<=DATE_CREATE' => '2024-12-31T23:59:59'
]
```

**Несколько значений (ИЛИ):**
```php
'filter' => [
    'STATUS_ID' => ['NEW', 'IN_PROCESS']
]
```

### Сортировка

```php
'order' => [
    'DATE_CREATE' => 'DESC',  // По убыванию
    'TITLE' => 'ASC'          // По возрастанию
]
```

## 6. Пагинация

### Параметр start

Для постраничной навигации используется параметр `start`:

```php
// Первая страница (0-49)
'start' => 0

// Вторая страница (50-99)
'start' => 50

// Третья страница (100-149)
'start' => 100
```

### Алгоритм полной выборки

```php
$allItems = [];
$start = 0;

do {
    $response = $bitrix24->call('crm.lead.list', [
        'start' => $start
    ]);
    
    $items = $response['result'];
    $allItems = array_merge($allItems, $items);
    
    $start += 50;
    
    // Если вернулось меньше 50, значит это последняя страница
} while (count($items) === 50);
```

### Поле next в ответе

Начиная с некоторых версий Bitrix24 добавлено поле `next`:

```json
{
    "result": [...],
    "next": 50,
    "total": 237
}
```

Если `next` отсутствует - данные закончились.

## 7. Работа с пользовательскими полями

### Типы пользовательских полей

Пользовательские поля имеют префикс `UF_CRM_`:

- `UF_CRM_1234567890` - текстовое поле
- `UF_CRM_CUSTOM_FIELD` - кастомное поле

### Создание пользовательского поля

Через REST API нельзя создать поле, только через интерфейс или модуль.

### Работа с пользовательскими полями

**Получение списка полей:**
```php
$fields = $bitrix24->call('crm.lead.fields');
```

**Установка значения:**
```php
[
    'fields' => [
        'UF_CRM_1234567890' => 'Значение'
    ]
]
```

**Типы значений:**
- Строка: `'Текст'`
- Число: `12345`
- Дата: `'2024-01-15'`
- Список: `123` (ID значения)
- Множественный список: `[123, 456]`

## 8. Связь между сущностями

### Иерархия связей

```
Компания (Company)
    ├── Контакты (Contacts)
    └── Сделки (Deals)
            └── Контакты (Contacts)
```

### Привязка контакта к компании

```php
// Создание контакта с компанией
crm.contact.add([
    'fields' => [
        'NAME' => 'Иван',
        'COMPANY_ID' => 123
    ]
])
```

### Привязка сделки к контакту и компании

```php
// Создание сделки
crm.deal.add([
    'fields' => [
        'TITLE' => 'Продажа',
        'CONTACT_ID' => 456,    // Один контакт
        'COMPANY_ID' => 123
    ]
])
```

### Множественная привязка контактов к сделке

Используется отдельный метод `crm.deal.contact.add`:

```php
// Добавить контакт к сделке
crm.deal.contact.add([
    'id' => 789,           // ID сделки
    'fields' => [
        'CONTACT_ID' => 456,
        'SORT' => 100,
        'IS_PRIMARY' => 'Y'
    ]
])
```

## Вопросы для собеседования

### Базовые вопросы

**1. Какие основные методы есть для работы с лидами?**

**Ответ:**
- `crm.lead.add` - создание
- `crm.lead.update` - обновление
- `crm.lead.get` - получение по ID
- `crm.lead.list` - список с фильтрацией
- `crm.lead.delete` - удаление
- `crm.lead.fields` - список полей

**2. Чем отличается лид от сделки?**

**Ответ:**
- **Лид** - потенциальный клиент, еще не квалифицирован
- **Сделка** - активная продажа с этапами воронки
- Лид конвертируется в Контакт/Компанию/Сделку
- У лида нет воронки продаж
- У сделки есть стадии (STAGE_ID) и воронки

**3. Как работают множественные поля (телефон, email)?**

**Ответ:**
- Хранятся как массив объектов
- Каждый элемент содержит `VALUE` и `VALUE_TYPE`
- При обновлении передается полный массив (заменяет все)
- Типы: WORK, MOBILE, HOME и т.д.
- Можно указать несколько телефонов/email разных типов

**4. Какие операторы фильтрации поддерживаются?**

**Ответ:**
- `=` - равно (по умолчанию)
- `!` - не равно
- `>`, `<`, `>=`, `<=` - сравнение
- `%` - LIKE (поиск подстроки)
- `=%` - LIKE с указанием позиции
- Для проверки на пустоту: `'!PHONE' => false`

**5. Как получить все записи, если их больше 50?**

**Ответ:**
```php
$allItems = [];
$start = 0;

do {
    $response = $bitrix24->call('crm.lead.list', ['start' => $start]);
    $items = $response['result'];
    $allItems = array_merge($allItems, $items);
    $start += 50;
} while (count($items) === 50);
```

### Продвинутые вопросы

**6. Как создать лид с несколькими телефонами?**

**Ответ:**
```php
crm.lead.add([
    'fields' => [
        'TITLE' => 'Клиент',
        'PHONE' => [
            ['VALUE' => '+7 (999) 111-11-11', 'VALUE_TYPE' => 'WORK'],
            ['VALUE' => '+7 (999) 222-22-22', 'VALUE_TYPE' => 'MOBILE']
        ]
    ]
])
```

**7. Как найти все сделки конкретного контакта?**

**Ответ:**
```php
crm.deal.list([
    'filter' => [
        'CONTACT_ID' => 123
    ]
])
```

**8. Как привязать несколько контактов к одной сделке?**

**Ответ:**
1. Создать сделку
2. Использовать `crm.deal.contact.add` для каждого контакта
3. Или указать основной контакт через `CONTACT_ID` при создании

```php
// Основной контакт при создании
crm.deal.add(['fields' => ['CONTACT_ID' => 123]]);

// Дополнительные контакты
crm.deal.contact.add(['id' => 789, 'fields' => ['CONTACT_ID' => 456]]);
```

**9. Какие стандартные статусы у лида?**

**Ответ:**
- `NEW` - новый
- `IN_PROCESS` - в работе
- `PROCESSED` - обработан
- `CONVERTED` - конвертирован
- `JUNK` - некачественный

Можно добавлять свои через настройки CRM.

**10. Как обновить только один телефон, не затронув остальные?**

**Ответ:**
1. Получить текущие данные через `crm.lead.get`
2. Найти нужный телефон в массиве `PHONE`
3. Изменить его
4. Отправить весь массив через `crm.lead.update`

```php
// Получаем лид
$lead = $bitrix24->call('crm.lead.get', ['id' => 123]);
$phones = $lead['result']['PHONE'];

// Меняем рабочий телефон
foreach ($phones as &$phone) {
    if ($phone['VALUE_TYPE'] === 'WORK') {
        $phone['VALUE'] = '+7 (999) 999-99-99';
    }
}

// Обновляем
$bitrix24->call('crm.lead.update', [
    'id' => 123,
    'fields' => ['PHONE' => $phones]
]);
```

## Частые ошибки

### 1. Забыли указать обязательное поле

**Ошибка:**
```json
{
    "error": "ERROR_CORE",
    "error_description": "Required fields: TITLE"
}
```

**Решение:**
Проверить обязательные поля через `crm.lead.fields`:
```php
$fields = $bitrix24->call('crm.lead.fields');
foreach ($fields['result'] as $field => $props) {
    if ($props['isRequired']) {
        echo "$field is required\n";
    }
}
```

### 2. Неправильный формат множественного поля

**Ошибка:**
```php
// ❌ Неправильно
'PHONE' => '+7 (999) 123-45-67'
```

**Правильно:**
```php
// ✅ Правильно
'PHONE' => [
    ['VALUE' => '+7 (999) 123-45-67', 'VALUE_TYPE' => 'WORK']
]
```

### 3. Попытка обновить поле только для чтения

**Ошибка:**
```php
// ❌ Нельзя изменить ID или DATE_CREATE
'fields' => [
    'ID' => 999,
    'DATE_CREATE' => '2024-01-01'
]
```

### 4. Неправильный оператор фильтрации

**Ошибка:**
```php
// ❌ Оператор пишется слитно с полем
'filter' => [
    'OPPORTUNITY' => '>10000'  // Неправильно
]
```

**Правильно:**
```php
// ✅ Оператор - часть ключа
'filter' => [
    '>OPPORTUNITY' => 10000
]
```

### 5. Забыли про пагинацию

**Проблема:**
Получили только первые 50 записей, а в базе их 500.

**Решение:**
Всегда проверять количество возвращенных записей и делать цикл с `start`.
